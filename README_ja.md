=====
軽量で高性能なインターネットリレーチャットデーモンです。高速かつ信頼性の高い動作を実現するよう設計されており、1997年からircネットワークの背骨として機能しています。


## 要件
ircd-hybridの動作には、GNU/Linux、GNU/Hurd、*BSDファミリー、macOSなどのPOSIX準拠オペレーティングシステムが必要です。

## インストール
ircd-hybridの設定やコンパイル方法については、[INSTALL.md](INSTALL.md)ドキュメントをご覧ください。
